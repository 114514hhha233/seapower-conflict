# 海权冲突 · 3D 战术海战（试玩版）

手机横屏点击即玩的 3D 战术海战试玩版。单机、无内购、不联网。

- 战役 10 关 + 遭遇战 12 级
- 舰船 / 导弹图鉴
- 舰空导弹、近防炮、舱段损伤与沉没过程
- 军语播报：方位 / 航向逐字读，距离用自然数字
- 底部「视角」抽屉：本舰 / 空中 / 目标 / 导弹 / 拦截
